# ExpenseControl
Um projeto de controle de receitas e despesas, desenvolvido com HTML, CSS e JavaScript, utilizando firebase para autenticação de usuários e armazenamento dos dados.

O projeto foi desenvolvido com o objetivo de praticar e desenvolver uma aplicação web um pouco mais completa (mesmo assim não asseguro que esta aplicação terá um bom desempenho para uso mobile!!).

Acesso ao site:

Funcionalidades:

* Cadastro de usuários.
* Login e autenticação.
* Recuperação de senha por email.
* Proteção básica de páginas para usuários autenticados.
* Cadastro de receitas e despesas.
* Edição de transações.
* Exclusão de edições.
* Visualização das transações cadastradas.
* Separação entre receitas e despesas.
* Ordenação das transações por data.
* Associação das transações ao usuário autenticado.
* Validação dos formulários.
* Indicadores de carregamento durante operações.


Tecnologias utilizadas:

* HTML5.
* CSS3.
* JavaScript.

BackEnd/Serviços:

* Firebase Authentication.
* Firebase Firestore.

Firebase: O projeto utiliza o Firebase para fornecer os serviços de autenticação e armazenamento dos dados.
Firebase Authentication: Responsável pelo gerenciamento dos usuários, incluindo:
* Cadastro.
* Login.
* Logout.
* Recuperação de senha.
* Verificação do estado de autenticação.
